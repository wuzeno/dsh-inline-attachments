The three `screenshot-*.jpg` files are cropped/re-encoded copies of screenshots supplied by the project owner for this release. They illustrate actual DSH UI behavior with synthetic test data. They are not benchmark results. Host UI, wallpapers, model names and other third-party visual elements remain the property of their respective rights holders; the code's MIT license does not purport to relicense those elements.

The `figure-*.svg`, matching PNG previews, and `project-banner` images are original explanatory illustrations generated by this repository's `scripts/render-release-art.py`. Their editable SVG sources and rendering script are included under the repository's MIT license. They are conceptual engineering/HCI diagrams, not results of a scientific usability study, a publication endorsement, or measured performance claims.

The configured external image-generation channel was unavailable during release preparation; these figures were authored programmatically as editable vector graphics rather than represented as outputs of that service.
